# financeappmvp
finance investment helper tool

**portfolio classic**
- Stock counts (10, 15, 20, 25, 30, 40, 50)
- Risk levels (Conservative, Moderate, Aggressive)
- Investment horizons (1M, 2M, 3M, 6M, 1Y+)
- Rebalancing frequencies (Weekly, Bi-weekly, Monthly, Quarterly, Semi-annual)
